# 每日股票交易记录（pureClientA）

轻量纯前端应用，用于记录每日股票交易，数据保存在浏览器 `IndexedDB`（已从 localStorage 迁移）。无需后端，直接用浏览器打开 `index.html` 即可。

主要功能

- 新增/删除交易（日期、代码、买/卖、数量、价格、金额）
- 按时间 / 代码 筛选记录
- 导出为 CSV 文件
- 清空所有资料（需确认，不可恢复）
- 汇总显示净现金流
- 自动从 localStorage 迁移数据到 IndexedDB

文件

- `index.html` - 页面
- `styles.css` - 样式
- `app.js` - 业务逻辑（IndexedDB 存取、UI 绑定）
- `StockCodeList.txt` - 股票代码列表（用于生成内置股票数据）

快速使用

1. 在浏览器中打开 `pureClientA/index.html`（直接双击或通过本地静态服务器）。
2. 新增交易：填写表单并点击“保存交易”。
3. 在“交易记录”表格中删除记录。
4. 使用筛选栏按日期或代码筛选记录：
   - 选择日期范围
   - 选择或输入股票名称
   - 点击“筛选”按钮应用筛选条件
   - 点击“重置”按钮清除筛选条件
5. 点击“导出 CSV”下载当前筛选后的数据。
6. 点击“清空所有资料”按钮可清空所有交易记录（需确认，不可恢复）。

开发者调试

- 数据存储：`TradesDB`（IndexedDB）
- 浏览器控制台可使用：
  - `window._loadTrades()` - 手动重新加载并渲染数据
  - `window._applyFilters()` - 手动应用筛选条件
  - `window._exportToCSV()` - 手动导出 CSV
- 数据迁移：首次启动时会自动从 localStorage 键 `trades_v1` 迁移数据到 IndexedDB

技术改进

- **存储优化**：已迁移到 IndexedDB，支持更大量的数据存储
- **筛选功能**：实现了按日期和股票代码的筛选
- **导出功能**：支持导出为 CSV 文件，便于数据分析
- **数据迁移**：自动从 localStorage 迁移到 IndexedDB，保持数据连续性
- **异步操作**：所有数据操作均为异步，提高应用响应性
